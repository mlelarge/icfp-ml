# Project

The course project gives you the chance to put the concepts covered in class into practice on a topic that interests you.
Any problem that can be addressed using a machine learning approach is a valid choice.
We encourage you to take a hands-on, applied approach, with an emphasis on designing and training a machine learning model.


## Agenda

- [Project proposal](https://docs.google.com/document/d/1MyKRbci86dwbojGTatfn15Ji_Xfxc8f0_5qFTO_ZTAI/edit?usp=sharing), due by **March 12, 2026**.
- Project code and defense, due by **April 2, 2026**.


## Instructions and evaluation guidelines

- Groups may consist of up to 3 students.
- Each group must deliver a presentation at the end of the project, explaining the motivation behind their idea and summarizing their findings. The presentation should cover the following sections:
	* Introduction - Problem Statement: a clear description of the problem being addressed
	* Methodology: an overview of the dataset, neural network architecture, and training procedure (with visual illustrations when possible)
	* Results: qualitative outcomes (e.g. generated images, segmentation boxes…) and quantitative outcomes (summary of final performance with metrics, loss curves, etc.)
- Grading will be based on two main components:
	* Quality and originality of the project (Are each group member's contributions clearly identified? What was implemented in relation to the original research questions? What was borrowed from existing code repositories?)
	* Presentation of the project (structure, clarity of figures and tables, overall quality of the presentation, and responses to questions)
